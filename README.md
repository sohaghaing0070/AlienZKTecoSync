## ✨ Key Features

- ⚡ **Real-Time & Polling Sync:** Continuous automated attendance record synchronization.
- 🌐 **ADMS / Cloud Push Receiver:** Built-in HTTP server listening for device push logs.
- 🗄️ **Multi-Database Support:** Direct native support for Oracle DB, MySQL, SQLite, and Webhooks.
- 📡 **Webhooks & ERP Integrations:** Dispatch punch records in real time to custom REST APIs.
- 🔒 **Machine-Locked Licensing:** Enterprise security protection.
- 🛡️ **Zero Dependency & 100% Offline:** Fully self-contained native Windows executable (no Python or external runtimes required).
- 🔄 **Windows Auto-Start:** Background system tray minimize & silent Windows boot startup.

## 🚀 Installation & Usage

### Method 1: Using the Installer (`.exe`)
1. Download `AlienZKTecoSync_v2.5_Setup.exe`.
2. Double-click the file to launch the **Alien Soft Setup Wizard**.
3. Choose your installation directory and click **Install**.
4. Launch the application from your Desktop shortcut or Start Menu.

### Method 2: Using the Portable Package (`.zip`)
1. Download and extract `AlienZKTecoSync_v2.5_Portable.zip`.
2. Run `Launch_AlienZKTecoSync.bat` or `AlienZKTecoSync.exe`.
